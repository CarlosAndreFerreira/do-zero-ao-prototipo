# Ferramentas, por objetivo

[Voltar ao início](README.md)

Escolhe pelo que precisas de fazer, não pelo nome da ferramenta. Em cada objetivo, a primeira linha é a sugestão para começar.

**Como ler a coluna «Tipo»:**

- **Grátis:** não pagas para usar o essencial.
- **Plano grátis:** há uma versão gratuita com limites; o resto é pago.
- **Open source:** o código é aberto, com uma licença reconhecida.
- **Local:** corre no teu computador e os dados não saem dele.

Os limites e preços mudam com frequência. Confirma sempre na página oficial antes de decidir.

## Começa por aqui

Se só tens cinco minutos, escolhe a linha que descreve o que precisas agora.

| Preciso de… | Experimenta | Porquê |
|---|---|---|
| Explicar melhor a minha ideia | [Gemini](https://gemini.google.com/) | Conversa em português e ajuda-te a preencher o modelo. |
| Mostrar como seria o ecrã | [Stitch](https://stitch.google.com/) | Desenha ecrãs de app ou site a partir de uma frase. |
| Carregar num botão e ver funcionar | [Gemini Canvas](https://gemini.google.com/) | Escreve a página e mostra-a a funcionar ao lado. |
| Usar IA sem enviar dados para fora | [Jan](https://jan.ai/) | Corre no teu computador, mesmo sem internet. |

## 1. Clarificar a ideia

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [Gemini](https://gemini.google.com/), [ChatGPT](https://chatgpt.com/) ou [Claude](https://claude.ai/) | Plano grátis | Reduzir a ideia a uma pessoa e uma ação; preencher o modelo. |
| [Gemini Notebook](https://notebook.google/) (antigo NotebookLM) | Grátis | Fazer perguntas sobre os teus próprios documentos (regulamentos, notas, estudos). |

## 2. Mostrar um ecrã ou criar uma página que podes experimentar

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [Gemini Canvas](https://gemini.google.com/) | Grátis | Pedir uma página e vê-la a funcionar no mesmo ecrã. Foi o que usámos no workshop. |
| [Stitch](https://stitch.google.com/) | Grátis | Desenhar ecrãs de app ou site a partir de uma descrição ou de um esboço. Serve para mostrar a ideia; os botões ainda não funcionam. |
| [Lovable](https://lovable.dev/) | Plano grátis | Protótipos com vários ecrãs, a partir de uma descrição. |
| [Bolt.new](https://bolt.new/) | Plano grátis | Semelhante ao Lovable, com pré-visualização. |
| [v0](https://v0.app/) | Plano grátis | Ecrãs e interfaces a partir de uma descrição. |
| [Glide](https://www.glideapps.com/) | Plano grátis | Uma app a partir de uma folha de cálculo que já tenhas. |

Atenção: em vários destes construtores, as apps feitas no plano gratuito ficam visíveis para quem tiver o link. Não ponhas lá dados reais.

## 3. Experimentar modelos de IA no browser

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [NVIDIA Build](https://build.nvidia.com/) | Plano grátis | Experimentar dezenas de modelos abertos sem instalar nada. |
| [Hugging Face Spaces](https://huggingface.co/spaces) | Grátis | Demos de modelos abertos: imagens, voz, transcrição e mais. |
| [Google AI Studio](https://aistudio.google.com/) | Plano grátis | Experimentar os modelos Gemini e preparar o passo seguinte. |

## 4. Correr a IA no teu computador

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [Jan](https://jan.ai/) | Open source, local | Uma app de chat que funciona sem internet. A mais simples para começar. |
| [Ollama](https://ollama.com/) | Open source, local | Correr modelos abertos; muito usado por outras ferramentas. |
| [LM Studio](https://lmstudio.ai/) | Grátis, local | Descarregar e usar modelos com uma interface simples. O código não é aberto. |
| [AnythingLLM](https://anythingllm.com/) | Open source, local | Conversar com os teus documentos sem os enviar para fora. |

## 5. Pôr IA dentro da tua aplicação (API)

Só precisas disto quando a própria aplicação tem de pedir algo à IA enquanto alguém a usa.

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [NVIDIA Build](https://build.nvidia.com/) | Plano grátis | Créditos gratuitos para usar modelos abertos por API. |
| [Google AI Studio](https://aistudio.google.com/) | Plano grátis | Chave gratuita para a API do Gemini. |
| [Groq](https://console.groq.com/) | Plano grátis | Respostas muito rápidas com modelos abertos. |
| [OpenRouter](https://openrouter.ai/) | Plano grátis | Vários modelos num só sítio, alguns gratuitos. |

## 6. Ligar peças sem programar

| Ferramenta | Tipo | Para quê |
|---|---|---|
| [n8n](https://n8n.io/) | Código disponível | Automatizar tarefas arrastando blocos. A licença limita alguns usos comerciais, por isso não é open source no sentido estrito. |
| [Flowise](https://flowiseai.com/) | Open source | Montar assistentes de IA com blocos visuais. |
| [Langflow](https://www.langflow.org/) | Open source | Semelhante ao Flowise. |
| [Make](https://www.make.com/) ou [Zapier](https://zapier.com/) | Plano grátis | Ligar apps que já usas, sem instalar nada. |

## Queres mais opções?

Estas listas são grandes e úteis para explorar, mas não precisas delas para dar o primeiro passo:

- [awesome-free-ai-tools](https://github.com/mdruhulkuddus/awesome-free-ai-tools): catálogo de ferramentas com plano gratuito, com as limitações de cada uma.
- [awesome-vibe-coding](https://github.com/awesome-vibe-coding/awesome-vibe-coding): ferramentas para construir software com IA.
